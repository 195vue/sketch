# 角色权限矩阵

## 一、系统级角色（登录时确定）

### 1. 超级管理员 (super_admin)
| 维度 | 详情 |
|------|------|
| 侧边栏菜单 | 项目管理 + 系统管理（全部子菜单） |
| 数据范围 | 所有租户、所有项目、所有数据 |
| 可访问页面 | 全部页面 |
| 特殊能力 | 创建/删除租户、启停租户、修改系统级配置、数据加密配置 |

### 2. 租户管理员 (tenant_admin)
| 维度 | 详情 |
|------|------|
| 侧边栏菜单 | 项目管理 + 系统管理（部分菜单） |
| 数据范围 | 仅限本租户下的项目、成员、图纸、任务 |
| 可访问页面 | 项目管理、公司人员管理、并发任务管理、系统日志 |
| 特殊能力 | 创建项目、管理本租户人员、配置租户级出图规范 |
| 不能做 | 创建/删除租户、修改系统级加密配置、修改全局系统设置 |

### 3. 普通用户 (cartographer / auditor / browser)
| 维度 | 详情 |
|------|------|
| 侧边栏菜单 | 仅「项目管理」（无系统管理入口） |
| 数据范围 | 仅自己已加入的项目 |
| 可访问页面 | 项目管理、图纸管理（进入项目后）、项目成员管理（进入项目后） |
| 特殊能力 | 权限由项目角色决定 |

## 二、项目级角色（进入项目后确定）

### 权限对照表

| 操作权限 | 代码标识 | 项目管理员 | 制图员 | 审核员 | 浏览员 |
|----------|----------|:----------:|:------:|:------:|:------:|
| 上传草图 | upload | ✅ | ✅ | ❌ | ❌ |
| AI出图 | generate | ✅ | ✅ | ✅ | ❌ |
| 下载DWG | download | ✅ | ✅ | ✅ | ❌ |
| 删除文件 | delete | ✅ | ✅ | ❌ | ❌ |
| 查看图纸 | view | ✅ | ✅ | ✅ | ✅ |
| 配置权限 | configure | ✅ | ❌ | ❌ | ❌ |

### 各角色页面行为

#### 项目管理员 (project_admin)
- **图纸管理**: 上传草图、AI加强、批量出图、下载、删除、重命名 全部可用
- **成员管理**: 添加成员、移除成员、分配角色、配置权限矩阵 全部可用
- **项目详情**: 编辑项目信息、切换项目状态

#### 制图员 (cartographer)
- **图纸管理**: 上传、AI加强、出图、下载、删除、重命名 全部可用
- **成员管理**: 只能查看成员列表，不能添加/移除/改角色
- **项目详情**: 只能查看项目信息

#### 审核员 (auditor)
- **图纸管理**: 只能查看草图预览、查看AI处理结果、下载DWG
- **看不到**: 上传按钮、AI加强按钮、批量出图按钮、删除按钮
- **成员管理**: 只能查看成员列表
- **项目详情**: 只能查看

#### 浏览员 (browser)
- **图纸管理**: 只能查看图纸列表和预览
- **看不到**: 上传、出图、下载、删除等所有操作按钮
- **成员管理**: 只能查看
- **项目详情**: 只能查看

## 四、权限校验实现

1. **路由守卫** (App.tsx)
   - ProtectedRoute: 未登录 → 跳登录页
   - AdminRoute: 非管理员 → 跳回项目列表

2. **按钮级权限** (Drawings.tsx)
   - hasPermission('upload') 动态显示/隐藏操作按钮
   - 无权限的按钮不渲染

3. **菜单级权限** (Sidebar.tsx)
   - 非管理员不显示「系统管理」菜单
   - 租户管理员仅看到部分系统管理子菜单

4. **数据隔离** (useStore.ts)
   - super_admin: 全部数据
   - tenant_admin: 仅本租户数据
   - 普通用户: 仅已加入项目数据
