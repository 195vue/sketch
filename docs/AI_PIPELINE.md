# AI处理流水线说明

## 概述

AI处理流水线是系统核心功能，将用户上传的草图（JPG/PNG/BMP/PDF）通过9个阶段自动处理，最终生成标准DWG图纸。

---

## 9个处理阶段

### 阶段1: 自动图像预处理
| 项目 | 说明 |
|------|------|
| 功能 | 自动去噪、灰度化、线条增强、倾斜校正、干扰剔除 |
| 耗时参考 | 约2.5秒 |
| 子步骤 | 图像去噪 → 灰度化处理 → 线条增强 → 倾斜校正 → 干扰剔除 |

### 阶段2: AI目标自动识别
| 项目 | 说明 |
|------|------|
| 功能 | 自动识别杆位、光缆路由、分纤点、接头、线路走向 |
| 耗时参考 | 约3.5秒 |
| 子步骤 | 杆位识别 → 光缆路由识别 → 分纤点识别 → 接头识别 → 线路走向识别 |

### 阶段3: 图形自动矢量化
| 项目 | 说明 |
|------|------|
| 功能 | 像素图自动转为矢量图形，提取坐标、长度、拓扑关系 |
| 耗时参考 | 约3秒 |
| 子步骤 | 像素转矢量 → 坐标提取 → 长度计算 → 拓扑关系构建 |

### 阶段4: 自动语义标注
| 项目 | 说明 |
|------|------|
| 功能 | 按运营商规范生成杆号、路由编号、分纤类型、敷设方式 |
| 耗时参考 | 约2.5秒 |
| 子步骤 | 杆号自动生成 → 路由编号 → 分纤类型标注 → 敷设方式标注 |

### 阶段5: 标注自动校验纠错
| 项目 | 说明 |
|------|------|
| 功能 | 自动检测重复编号、缺失标注、逻辑错误并修正 |
| 耗时参考 | 约2秒 |
| 子步骤 | 重复编号检测 → 缺失标注检测 → 逻辑错误检测 → 自动修正 |

### 阶段6: 自动图层分层
| 项目 | 说明 |
|------|------|
| 功能 | 按标准分为杆路层、光缆层、分纤层、标注层、辅助层 |
| 耗时参考 | 约1.5秒 |
| 子步骤 | 杆路层 → 光缆层 → 分纤层 → 标注层 → 辅助层 |

### 阶段7: 图层属性自动配置
| 项目 | 说明 |
|------|------|
| 功能 | 自动设置颜色、线型、线宽、字体、样式 |
| 耗时参考 | 约1.5秒 |
| 子步骤 | 颜色配置 → 线型配置 → 线宽配置 → 字体样式配置 |

### 阶段8: DWG图纸生成
| 项目 | 说明 |
|------|------|
| 功能 | 根据AI识别结果及通信竣工图标准，生成标准DWG |
| 耗时参考 | 约3秒 |
| 子步骤 | 图框生成 → 图层数据写入 → 标注写入 → DWG文件生成 |

### 阶段9: DWG在线预览
| 项目 | 说明 |
|------|------|
| 功能 | 生成完成后支持在线预览DWG内容 |
| 耗时参考 | 约1秒 |
| 子步骤 | DWG加载 → 在线渲染 → 交互预览 |

## 页面交互

### 入口
1. 图纸管理页面 → 草图操作栏点击「AI处理」按钮（⚡图标）
2. 批量操作：勾选多个草图后点击「批量出图」

### 页面元素
- **顶部**: 返回按钮、草图名称、「开始AI处理」/「重置」按钮、完成后显示「在线预览」/「下载DWG」
- **流水线进度条**: 9个阶段卡片，显示每个阶段的图标、标题、状态和进度
- **详情面板**: 左侧显示每个阶段的详细子步骤和进度条；右侧显示实时处理日志
- **完成面板**: 显示「处理完成」提示，提供预览和下载入口

### 状态流转
```
pending → processing → completed
```

### 权限要求
- 需要 `generate` 权限才能看到「AI处理」按钮
- 完成后需要 `view` 权限预览、`download` 权限下载

## AI加强功能（训练数据喂养）

### 入口
图纸管理页面右上角「AI加强」按钮

### 功能
- 上传标识数据给AI模型
- 支持标注规则配置
- 提升AI识别准确率

---

## 技术要点

1. **全程自动化**: 点击出图后无需人工干预
2. **无线条失真**: DWG图纸保证线条完整
3. **图层不丢失**: 5个标准图层完整保留
4. **标注不错乱**: 自动校验确保标注逻辑正确
5. **云端处理**: 支持并发任务，不阻塞
